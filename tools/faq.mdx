Here are the questions I get most often about the tools on this site. If something here doesn't answer what you're looking for, the last section has a pointer to where you can ask directly.

<AccordionGroup>
  <Accordion title="Are these tools free?">
    Yes — completely free, no strings attached. There are no ads, no subscription tiers, no sign-up required, and no "premium" version hiding features behind a paywall. These tools exist because they're useful to me, and making them free to everyone else costs me nothing extra.
  </Accordion>

  <Accordion title="Is my data private?">
    All processing happens entirely on your device, inside your browser tab. Nothing you type or paste into these tools is ever transmitted to a server — there is no backend receiving your data. You can confirm this yourself by opening your browser's developer tools, switching to the Network tab, and watching for outgoing requests while you use a tool. You won't see any.
  </Accordion>

  <Accordion title="Do the tools work offline?">
    Yes, once the page has fully loaded, the tools continue to work without an active internet connection. All the logic runs in JavaScript that was already downloaded to your browser when you opened the page. This makes them safe to use in environments with restricted or unreliable connectivity.
  </Accordion>

  <Accordion title="What browsers are supported?">
    The tools are tested and supported on all major modern browsers:

    - **Chrome** 90 and above
    - **Firefox** 88 and above
    - **Safari** 14 and above
    - **Edge** 90 and above

    No plugins, extensions, or special browser settings are required. Internet Explorer is not supported.
  </Accordion>

  <Accordion title="Can I request a new feature?">
    Absolutely. If there's an operation or format you wish a tool supported — or if you have an idea for an entirely new tool — open a GitHub issue with the `feature request` label and describe what you'd like and why it would be useful. I can't promise a timeline, but I genuinely read every suggestion and the best ones tend to end up getting built.
  </Accordion>

  <Accordion title="Can I use these tools in my own project?">
    Yes. All source code is published under the MIT license, which means you're free to read it, fork it, adapt it, and include it in your own projects — personal or commercial — as long as you retain the original license notice. A link back or a mention is always appreciated but never required.
  </Accordion>

  <Accordion title="How were the tools built?">
    Each tool is written in vanilla JavaScript or TypeScript, depending on how complex the logic gets. I deliberately avoid heavy frontend frameworks for these utilities — no React, no Vue, just standard browser APIs and the occasional small, well-maintained library for things like YAML parsing. The goal is that someone who knows basic JavaScript can open the source, understand what's happening, and modify it without needing to set up a build pipeline.
  </Accordion>
</AccordionGroup>

<Note>
  If your question isn't answered here, feel free to [open a GitHub issue](https://github.com/mx-quan). Tag it with the `question` label and I'll do my best to reply promptly.
</Note>
