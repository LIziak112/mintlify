Every tool on this site runs directly in your browser. There's nothing to install, no account to create, and no data sent to any server. You open the page, use the tool, and leave — it's as simple as that. Whether you're on a work machine, a public computer, or a phone, the tools are ready without any friction.

## Using a Tool

<Steps>
  <Step title="Navigate to the tool page">
    Pick a tool from the sidebar or the [overview page](/tools/overview). Each tool has its own dedicated page with instructions specific to what it does.
  </Step>
  <Step title="Paste or enter your input">
    Click into the input area and paste your text or data. Most tools also let you type directly, so you can work with small inputs without leaving the page.
  </Step>
  <Step title="Configure options if needed">
    Some tools offer options — like choosing a target format or selecting a case style. These are presented as simple dropdowns or toggle buttons, all visible on the page.
  </Step>
  <Step title="Copy or download the output">
    Once the tool has processed your input, the result appears in the output area. Use the copy button to grab it to your clipboard, or download it as a file if the tool supports that.
  </Step>
</Steps>

## Privacy

<Note>
  All processing happens locally in your browser. No input data is ever transmitted to a server or stored anywhere — not even temporarily. You can verify this by checking your browser's network tab while using any tool; you won't see any outgoing requests containing your data.
</Note>

## Compatibility

The tools are written with standard browser APIs and tested against all modern browsers. They work without any plugins, extensions, or special permissions. If you're running a reasonably up-to-date version of Chrome, Firefox, Safari, or Edge, everything should work exactly as expected. Internet Explorer is not supported — but if you're still using IE in this day and age, you have bigger problems than data formatting.
