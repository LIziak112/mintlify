Most of the tools here started as a five-minute frustration — some repetitive task I kept doing by hand that finally annoyed me enough to automate. Rather than reaching for a bloated web app or installing yet another dependency, I wrote something small, specific, and mine. Over time these little scripts accumulated, and it seemed wasteful to keep them buried in a local folder. So they live here now, polished just enough to be useful to someone other than me.

## Philosophy

Every tool on this site exists because I had an actual problem to solve — not because it seemed like a cool project. I try to keep each one focused on a single job: if it starts growing extra menus and settings, that's usually a sign it wants to be two tools instead of one. I also write the code so a stranger can read and extend it, because future-me is basically a stranger. And finally, if a standard library already does the job well, I use it rather than reinventing it — simplicity beats cleverness every time.
