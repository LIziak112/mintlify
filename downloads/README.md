# Skill downloads

These zip packages contain the full skill folders (SKILL.md + scripts + assets).

## Install for AI agents (recommended)

From the docs repo after clone, or using GitHub:

```powershell
npx skills add LIziak112/mintlify -s word-format
npx skills add LIziak112/mintlify -s mathtype-re-render
```

Or point at a single skill path:

```powershell
npx skills add https://github.com/LIziak112/mintlify/tree/main/skills/word-format
npx skills add https://github.com/LIziak112/mintlify/tree/main/skills/mathtype-re-render
```

## Manual / offline

1. Download `word-format.zip` or `mathtype-re-render.zip`
2. Extract to a folder you can reference
3. Tell your agent the skill path, or run scripts from the extracted `scripts/` directory
