# 习题册模板排版规则

本参考适用于“章节名称、题型、母题、子题、解析加粗”等自定义样式的双栏习题册。以用户提供的已排版 DOCX 为唯一版式权威，不用 Word 默认样式替代模板。

## 先检查

1. 用 `inspect_template.ps1` 读取模板的自定义样式名称和 `Equation.DSMT4` 数量。
2. 确认源文档和模板都是 `.docx`，并且输出路径是新文件。
3. 关闭用户自己打开的 Word/WPS 文档；脚本只关闭自己创建的 COM 实例，不关闭用户原有窗口。

## 推荐处理路径

对已有习题册进行模板化排版时，优先使用 `apply_exercise_template_ooxml.ps1`。该脚本在 DOCX ZIP 容器内处理 `word/document.xml` 和 `word/styles.xml`，复制模板的页面几何和自定义段落样式，同时复制源文档的其他 ZIP 部件。

不要用浏览器 HTML 粘贴或 `python-docx` 重建包含 MathType/OLE 的整篇文档。`Equation.DSMT4` 对象必须随源 DOCX 的 `word/embeddings`、关系、图片和 VML 部件一起保留；输出的标记数和嵌入部件数应与源文档一致。

## 双栏规则

- “题型一”保留在文档的首个内容位置。
- 其他“题型”必须在下一栏顶部开始，用段落内的 `<w:br w:type="column"/>`，不要用 page break。
- “检测题”和“检测题答案”都必须在新栏顶部开始。
- “反馈通道”、两个二维码和“题册调整”必须完整处于同一栏；反馈通道标题所在段落从新栏顶部开始。
- 母题之间沿用模板的正常段前/段后间距，不额外加栏断点、分页符或空白段。
- 只移除源文档中用于制造整页空白的空段分页符；不要删除有内容的段落或公式段落。

## 加粗规则

“解析”标题可使用模板的“解析加粗”样式。解析正文中的 `Step n` 标签通常是 MathType/OLE 对象；只保留该对象自身的视觉效果，清除冒号及冒号后的全部文字、公式运行上的直接 `w:b`/`w:bCs`。不要把公式转换成 OMML 或图片。

## 段落几何规则

- 普通正文、母题概述和解析正文映射到模板段落样式后，模板样式必须成为段落缩进和间距的唯一权威；清除源段落残留的直接 `w:ind` 和 `w:spacing`，避免源格式继续压过模板。
- 图题、图示、编号、显式居中/右对齐以及含自定义制表位的特殊布局段落保留自身几何设置，不做全局去缩进。
- `MTDisplayEquation` 独立公式段保留公式 OLE 本身，但按模板的实际段落行为标准化：删除公式前的定位 `<w:tab/>`，段前/段后设为 `0`，缩进设为 `0`，并显式左对齐。不要仅保留源样式及其居中制表位，否则源文档的错误布局会被继续带入输出。
- 删除无文字、无对象、无分页/分栏、无书签、无域代码和无节属性的真空段；带结构标记的空段不得按普通空行删除。
- 公式前后的 `xml:space="preserve"` 常用于正文与行内 MathType 对象之间的分隔；不要全局修剪文本空格，也不要删除全部保留空格属性。

## 验收顺序

1. 运行 `audit_exercise_template_ooxml.ps1`，检查栏断点、分页符、Step 直接加粗、公式标记、独立公式段样式、正文直接缩进和 OLE/媒体部件数量。
2. 用文档渲染工具（优先 `render_docx.py`，或 Word COM 导出 PDF）生成全部页面图像。
3. 逐页检查，不只抽取文本：确认题型/检测题起始栏、母题连续性、二维码完整性、公式未缺失、无重叠/截断。
4. OOXML 或版面有任何改动，都必须重新审计并重新渲染。
